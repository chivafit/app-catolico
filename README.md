# Plataforma Católica — MVP

MVP de uma plataforma católica focada em Momento Diário, Minha Igreja, eventos, campanhas, peregrinações, livraria/marketplace e monetização.

## Stack
- Next.js 16
- React 19
- TypeScript
- Supabase
- Vercel

**Tese:** A paróquia distribui. O conteúdo retém. A economia monetiza.
